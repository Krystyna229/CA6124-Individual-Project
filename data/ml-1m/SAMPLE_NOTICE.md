# MovieLens 1M repository sample

The reported experiments used the complete official MovieLens 1M
`ratings.dat` file (1,000,209 ratings). The official ZIP has MD5 checksum
`c4d9eecfca2ab87c1945afe126590906`.

If this repository copy of `ratings.dat` contains fewer records, it is only a
size-limited submission sample. Download the full dataset from GroupLens before
reproducing the reported tuning and final-test results.
